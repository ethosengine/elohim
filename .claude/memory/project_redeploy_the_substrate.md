The powerful are building AI on hyperscale clouds, primed by the actors who already control resources, intended to point AI *at* people. The same fundamental tools — open model weights, commodity hardware, the inference substrate itself — can be redeployed:

- On machines the powerful don't own (commodity GPUs, household hardware, edge devices)
- Primed by people they can't surveil (local context, intimate priming, peer wisdom)
- Governed by communities they can't acquire (P2P, DHT, no central choke point)

This is the rug-pull move. The powerful built the substrate intending to control us; we use it to write a new social contract beneath their feet. They remain free to join, free to leave — but cannot exert control over participants. **The freedom to dominate is the only one the architecture refuses.**

**Why:** Capture-resistance has to be structural, not aspirational. Manifestos that say "we won't be evil" get acquired and become evil. Architectures whose deployment shape makes capture cost more than it returns *can't* be acquired into hostility — the new owner inherits the same architecture, with the same ungovernable distribution. This is the mechanism that distinguishes the Elohim Protocol from "ethics-washed centralized AI."

**How to apply:** When someone asks "but how does this resist capture by big tech / state / capital?", answer with the inversion: "they built the tools, we redeploy them on substrate they can't own." Don't list architectural features (DHT, P2P, edge) as policies — describe them as the geometry of capture-resistance. Pair with the freedoms triplet: free to join, free to leave, not free to dominate.
