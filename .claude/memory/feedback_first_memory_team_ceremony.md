**Why:** The memory-team substrate (subagents + signal-driven ceremonies + _lib + timeline scaffold + LIFECYCLE.md) landed last week. This was the first run. The retrospective consolidates lessons before they decay into "obvious in hindsight."

**How to apply:**

- **Cadence**: signal-driven, not weekly. Triggers any of: MEMORY.md byte-budget ≥90%, audit-script substrate edit, 3+ sprint-results in one wing (14d window), manifesto edit, operator-invoked. Floor: monthly if no signal.
- **Team primitive**: single-agent four-lens debate is sufficient for routine ceremonies (≤10 candidates, no lens-disagreement). Wire TeamCreate for contested cases. The storyteller noticed in this ceremony that single-agent multi-lens "ventriloquizes" the least-fluent lens (here: historian's forensic voice was compressed). This is a real failure mode for contested decisions.
- **Convergence bias**: three-perspective convergence is a strong signal for cascade-roots but biases against forward-leaning items only one lens sees. Weight convergence ≈ 0.4 against vision-alignment ≈ 0.4 and quiet-but-load-bearing ≈ 0.2 in next ceremony's ranking.
- **Cartographer needs a Wave 1 surface pass** alongside librarian and historian — not just at Wave 2/3. Future-leaning items get under-surfaced without it.
- **Hard rules held**: two-signature tiny-delete (none invoked), story-must-be-canonical for graduate (kept 3 entries in HOLD pending operator-confirm), historian-confirms-forensic-value for memorialize (kept 1 entry as archive-without-graduation by inverting the criterion). The discipline produced clean cuts cheaply.
