Operator vision articulated 2026-06-13 (feat/frontend-eyes-sprint), provoked by the live doorway-alpha freeze + storage-node memory climb. The self-healing surface is NOT a dashboard — it is an **actuatable control plane** that is OBSERVABLE (every reliability primitive readable as a projection) and ACTUATABLE (tune/pause/resume/run-now/reset/quarantine/re-derive via typed contract), serving THREE consumers: a human operator, a future "controls" UI, and the real target — an **AI agent self-debugging FOR the agent runtime on the user's own device**.

**Four defining stances → one headline invariant (STRUCTURAL NO-OVERWHELM):**
1. **Self-protection & negotiation** — each node manages its own stability in front of peers; peers negotiate health; no operator required.
2. **Defense in depth & bilateral flow control** — WE OWN BOTH ENDPOINTS of every link, so we mandate TWO-WAY contracts (receiver advertises capacity, sender restrains to the window, BOTH enforce); independent limits layered per edge (Auto ceiling · inbound admission · outbound restraint · propagated backpressure · circuit-break · quarantine · elevate) so no single layer is load-bearing → no peer/runtime can EVER be overwhelmed.
3. **Resource-aware Auto defaults** — the node detects its container (cgroup cpu/mem/disk + peer count) and DETERMINISTICALLY derives optimal defaults (a video-game "Auto" preset; ceiling = the flow-control credit budget), operator override > Auto > safe floor. Hardcoded constants (worker_threads(4), 300s warm-up timeout) are the anti-pattern.
4. **Agent-actuatable** — every actuation is a bounded/audited/revocable REA action on `Mishpat::Commitment` + `delegates-compute` (see [[project_rea_compute_commitment_primitive]]), NOT an admin API key; blast radius = the granted, revocable commitment scope.

**Built on existing bones, generalizing ONE working precedent** (`render_semaphore ← compute_budget`, doorway main.rs:557-600): `peer_statuses`/`PeerStatusRecorded`/`record_health_attestation` (advertisement channel), `PullStatusInfo` tri-state, `PeerHealthRegistry` (needs `is_open()`), `FeedbackSignal::Quarantine` (exists, nothing consumes it), `WriteThroughState` admin override (the actuation template). Most of self-healing is wiring dark/one-way defenses into two-way contracts.

**The freeze re-diagnosis (this work overturned the overnight handoff):** doorway freeze = serial CPU-bound warm-up churn — `warm_stream::spawn_stream_task` loops ~10 broken upstreams sequentially through a 5× backoff ladder, and a per-stream 300s reqwest timeout EXCEEDS the ~150-210s liveness-kill window. NOT the single-worker/sync_channel wedge. P0 cure: timeout < kill window + total warm-up budget + consume `peer_statuses` to skip broken upstreams + `worker_threads=max(4,ceil(cpu.max)×k)`.
