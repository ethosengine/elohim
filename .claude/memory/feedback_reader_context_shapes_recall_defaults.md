**What the operator said (2026-09-11):** the context of who uses the recall tool — stated and
revealed personality, default preferences, capabilities and intent, across a spectrum of agents
(haiku, sonnet, opus, fable) and humans of varying capability — is very important to the defaults
the journey applies. Not being intentional about agent-context design leads to audience capture,
filter bubbles, rabbit-hole/radicalization pipelines and epistemic bifurcation. That is why recipes
(algorithms) must be governable EPR artifacts and their application a mishpat/middot negotiation.
Defaults and presets for a human or agent are part of a continuous negotiation of capabilities,
health, review of direction and feedback, aimed at maximizing the agency and usefulness of the one
using the tool.

**Why it bites:** the bounded-recall sprint's journey folds are keyed `reader=<who>`; the same
question produced three different journeys across Fable and two Sonnet readers. A single unlabelled
default is the filter bubble in embryo.

**How to apply:** when designing or tuning any recall/discovery default (ranking weights, scope,
budgets, provider, first-screen shape), route it through the seam actor sidecar
(`agent:<role>@<model>`, session claims, projected memory) ↔ recipe `defaults`/`change_authority`,
and record the reader on every fold. Never bake a tier's preference into code as the default for
all. COMPOSE with the existing accessibility-dimension capability spectrum in graphos — the lens
gradient `minimal|simple|standard|detail|debug|trace` (`graphos/src/designed/qahal/_lib/types.ts`),
viewer `CapabilityTier` (`mock-imagodei-profiles.ts`), and the element `@capability*` contract
(`elohim-elements/elohim-imagodei/cem-plugins/capability-contract.mjs`) — a lens per reader, not a
second spectrum. Target each reader's zone of proximal development: Fable vs Sonnet defaults should
feel tangibly different (passage located + one next command vs ranked candidates + omissions), with
honesty constant across lenses. Model presets ≈ static per model per domain; human presets are a
continuous imagodei (stated) ↔ sophia (revealed) negotiation, reviewed on folds and revealed to the
person so they can contest it. Held frontier on the plan `2026-09-11-bounded-recall-mastery-sprint.md` (ruling note).
