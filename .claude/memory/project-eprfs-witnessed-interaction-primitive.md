The **eprfs witnessed-interaction primitive** (2026-07-15 vision): a light-runtime on a machine witnesses interaction events on content-addressed objects — `.mp3` mins-listened, `.mkv` mins-watched, `.epub` pages-read, offline consumption honestly reconciled — and **peer-sync turns local witness into validated (notarized) witness**, REA-aggregated on the object's CID, **denominated in the substrate the interaction spends** (attention-minutes/pages, energy-joules, or governance-affirm/dismiss). Skeleton: *local witness → peer-validated → REA-aggregated on object CID*. Anti-enclosure: honest value reconciliation on content owned-by-no-one, so creators/stewards are credited without a platform capturing the ledger. Parent spec LANDED on dev: `genesis/docs/superpowers/specs/2026-07-15-eprfs-witnessed-interaction-primitive-design.md` (@bcda30d1d). **Two commitments:** (I) *Witness, don't pay* (no witnessed event auto-mints value/reach — no pool to drain); (II) *Denominate in the witnessable, never the claimed* (credit rides delivered-bytes/metered-joules/observable-effect; self-reported attention is **advisory-forever**). **Hinge decision (D1): ratify Option A** — the spec is incoherent under Option B (crediting claimed attention re-mints the proof-of-attention bounty). Two **preconditions** gate all wire code: consumer-blinded census (aggregate-without-a-subject) + the typed `recognition ─✗→ discovery` firewall (which must SEVER the already-live `contributor_presences::recognition_score` order-by edge, not assume greenfield).

**The "post" event = leaving the machine → adopted by a peer** (local authoring is private; *adoption* is the reach-bearing witnessed event). **Reach is re-affirmed at each peer adoption** — the witness ladder IS the reach-affirmation gradient. The **speed of propagation** across the peer graph is the governed quantity: a judgement call + a compute curve where **trust earns efficiency** (friction-gradient — trusted authors/content propagate faster/cheaper; an unresolved governance abstention or low standing costs propagation *speed*, never the right to author). **This is the advisory floor's non-blocking teeth:** no one is silenced, reach/adoption-velocity is *earned* — the honest anti-enclosure enforcement that works *without* the silicon and sharpens into a real reach-ceiling exactly when peer-native elohim inference arrives to sit in the compute curve.

**Compute-source toggle + DHT-audited provenance (trajectory):** the escalation-endpoint compute (the elohim at H3) moves *this terminal (Claude Code) → API-key (hosted lab inference) → Elohim-Native peer inferencing endpoint* by a **config toggle, not a rewrite**; every agent's classifications/resolutions are **witnessed + audited on the DHT** (an agent's governance action IS a witnessed-interaction event — the classifier and the consumption primitive meeting at one witness ladder). v1 = an **honors-system contract** among the AI labs' agents (Anthropic/Google/OpenAI) + humans — honest, not apologetic, because a real ceiling needs the silicon.
