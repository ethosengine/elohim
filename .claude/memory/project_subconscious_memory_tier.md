When memory loses conscious reach (through reach-drop from bad-propagation, or natural decay, or compaction superseding the original) it does not vanish — it **submerges to an encrypted stewardship tier**:

- Visible only to elohim agents (the human's own elohim AND other elohim in the network as governance permits)
- Not surfaced on default human-facing surfaces
- Not network-discoverable through normal queries
- Subject to the **same dream/compaction lifecycle** as conscious memory (the comet shape applies — subconscious memory still decays, merges, forgets; submerging is not "preserved forever in encrypted form")
- **Surface-able** by two paths:
  - *Intentional facing* — the human chooses to confront the memory; elohim restores it to conscious tier with whatever integration support is appropriate
  - *Pattern recurrence* — if the human keeps producing patterns that connect to a submerged memory (e.g., recurring misinformation propagation that traces back to a subconscious source), elohim can ambiently surface the connection (gentle nudge, not interruption — per "less pushy notifications")

**Three orthogonal attributes for any memory:**

1. **Tier** — episodic / semantic / manifesto (importance/permanence)
2. **Visibility** — conscious / subconscious / quarantined / forgotten (who can see)
3. **Validity interval** — `[start, end?]` (when it was/is true)

Lifecycle operations transform these attributes independently. Submerge is a visibility transition (conscious → subconscious). Surface is its inverse. Quarantine is a different visibility (→ evidence-restricted). Forget is the terminal visibility (→ released, audit-only).

**Why this is structurally important:**

Pure consequence-without-recovery is brittle. A protocol that drops reach for bad-propagation but offers no path back creates either silent dishonesty (people hide rather than face) or permanent disenfranchisement (people leave rather than rebuild). The submerge/surface pattern offers the **recovery loop**: the consequence is real (you can't see it on default surfaces, your reach is reduced) AND the path through is offered (face it intentionally, work the integration, elohim attests to the work, the relationship can re-form differently).

**This consciously mirrors human psychology.** The human psyche holds patterns we're not ready to face in subconscious — accessible to therapeutic work, accessible to insight from others (a friend, a counselor), surfaceable when patterns recur in waking life. The protocol borrows this wisdom: **the elohim is something like the counselor with full access; the human is the one who chooses when to face**. Healing happens through facing, not through forgetting.

**Connections to existing principles:**

- *Elohim as counsel — imagodei right to defense* — the elohim sees what the human can't and represents them well; subconscious memory access is the substrate enabling that representation
- *Elohim as specialist subagents* — different specialist elohim could surface different aspects (defender notices threat-pattern recurrence; advocate notices virtue-pattern dormancy; gate-discerner notices contradiction)
- *Graduated recovery authority — community always can* — community/network holds recovery substrate even when individual loses access; submerged memory is exactly this at the data-substrate layer
- *Socially derived security* — encrypted tier with multi-elohim access mirrors peer-held-shares pattern
- *Less pushy notifications — prefer ambient* — surfacing happens ambiently when patterns recur, not interruptively
- *Values-forward preference guards* — the human can have preferences about what's surface-able; values-forward, time-limited, tended
- *Comet shape memory lifecycle* — submerged memory is part of the comet's tail with different visibility, still subject to dream/compaction
- *Stewardship philosophy* — different stewards (the human, their elohim, network elohim) have different access at different times based on graduated capability

**Distinguishing from related primitives:**

- *Submerge ≠ forget* — forgotten memory is released (audit-only); submerged memory is held, accessible to elohim, surface-able
- *Submerge ≠ quarantine* — quarantined memory is contained-as-evidence (often known-bad, restricted distribution, available for restitution); submerged memory may not be bad at all, just no longer in conscious view
- *Submerge can co-exist with quarantine* — known-bad content can be both quarantined (for restitution accountability) AND submerged (out of conscious view); orthogonal axes
- *Surface ≠ promote* — promote moves up a tier (importance); surface moves up a visibility layer (conscious access)

**How to apply:**

- Reach-drop on bad-propagation should default to submerge, not forget — recovery loop must remain available
- Elohim agents need explicit subconscious-tier access primitives in the substrate (Rust elohim-agent layer, not Angular)
- Surface operations require human consent (intentional facing) OR elohim discernment with appropriate authority — never silent surfacing on default human-facing surfaces
- Pattern-recurrence detection that triggers ambient surfacing is itself a stewardship discipline — too aggressive becomes harassment; too passive lets harm continue. This deserves its own design pass.
- The recovery loop must be communicated as part of the values-forward disclosure: "yes consequence is real, yes there's a path through, here's what facing looks like"
- This deserves elaboration in the elohim-agent specification (autonomous memory hygiene + subconscious access protocols)
