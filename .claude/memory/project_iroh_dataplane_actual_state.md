**The keystone gap — code is MODE-EXCLUSIVE, spec wants DUAL-STACK:** `TransportBackend{Libp2p,Iroh}` (no Dual). main.rs builds `P2PNode` XOR `IrohNode` at boot (libp2p slot None in iroh mode, `main.rs:1457-1461`). So `main.rs:1741 if let (Some(libp2p_n),Some(iroh_n))` is NEVER true → the built+tested `DualGossipPublisher` is **structurally dead on the live path**. A single node cannot run both swarms today. Per-object cross-plane routing therefore needs a new `Dual` boot mode (both swarms co-resident) — that's the real "finish the dual plane" work, and it lights the dead dual-publish. NOTE the blob plane is special: its "libp2p fallback" (`IrohThenLibp2p`) is a LOCAL legacy SHA256 store read, not a swarm — so per-object blob A/B works in iroh mode WITHOUT dual swarms.
