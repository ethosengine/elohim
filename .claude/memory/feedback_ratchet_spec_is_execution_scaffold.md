Operator (2026-09-01): "the ratchet spec is just an execution principle because we've been struggling to finish/complete the feature.. we're close... but whatever we need to do to finish."

**Why:** the dataplane feature (habit `dataplane-convergence`) carries ~40 ledger deltas and no status flip; the ratchet lanes (R/P/F/D/S, 48 rungs) exist to make progress verifiable, not to define what the substrate is. Treating it as design authority re-litigates finished decisions and adds rungs instead of finishing.

**How to apply:** cite the ratchet spec for *which move/rung* a piece of work advances (M3, P7, F7…), design from the canonical architecture docs (e.g. `trust-as-efficiency-signal`), and bias every plan toward the smallest slice that flips a named red.
