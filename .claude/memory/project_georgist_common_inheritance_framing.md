Operator-directed framing (2026-07-24) for all corpus economic-stance work. Canonical home: values-forward Stance I.4 + glossary ("the common inheritance", "Jubilee / naḥalah", "self-sealing").

- Never lean on the literal 1879 "land" metaphor — readers hear dirt/farms and miss George. Use **"the common inheritance"** (name "what George called land" once for lineage).
- **The boundary test is reproducibility.** Labor + Capital are reproducible/earned → private (Capital is stored labor, so the corpus's labor-vs-inheritance *binary* is right despite George's triad). The common inheritance is non-reproducible/positional/community-created → graduates to the commons.
- Modern kin of "land" = **Platform/Protocol Monopoly**: social graphs, network effects, protocol/payment/search choke points, spectrum, the data commons, trained-AI value scraped from collective output. Name the phenomenon **"digital enclosure"** (Enclosure-Acts parallel; creators as digital sharecroppers, the algorithm as the rent).
- Thesis line: "Value created by community activity belongs to the community; value created by individual effort belongs to you."
- **Return mechanism (data dividend / digital LVT) stays in specs, never asserted live in gospel** (Stance V.1; hardware epic §8 is open "at the level of mechanism"). Elohim itself is the "p2p protocol as Georgist infrastructure" answer. Pairs with [[feedback-identity-sovereignty-ontology-guard]] — steward holds, never owns.
