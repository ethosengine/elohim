User rejects "babysitter" / "watcher" framing for autonomous agent loops that iterate on real work (CI pipelines, overnight builds, etc.). These are first-class agentic developers with the full dev cycle: claim work, understand, fix, verify, close or escalate.

**Why:** Framing shapes design. "Babysitter" implies passive monitoring and human rescue; "agentic developer" implies agency, ownership, definition-of-done, and clean escalation. The user wants first-class citizens in the dev org, not supervised processes.

**How to apply:** When brainstorming or naming autonomous-agent systems, use "agentic developer", "agent loop", "autonomous developer" or similar. Reserve "watcher"/"monitor" for strictly-read-only surfaces (e.g. a log summariser that posts but never writes). If user uses diminutive framing themselves, mirror the first-class framing back in your response.
