On 2026-09-23 a scratch worktree (for a landing batch off origin/dev) got `node_modules -> /projects/elohim/node_modules`
symlinks so gate-runner could resolve picomatch. A later `pnpm install --frozen-lockfile` run inside the worktree
followed the link and rewrote the MAIN checkout's node_modules: 2,044 top-level entries re-pointed into the scratch
`.pnpm` store and `.modules.yaml` was deleted, while the worktree's install aborted (`ERR_PNPM_ABORTED_REMOVE_MODULES_DIR_NO_TTY`
first, then a symlink error). A plain reinstall in the main checkout said "up to date" and left the bad links; the
repair was: delete the links pointing into the scratchpad, delete `node_modules/.modules.yaml`, then
`CI=true pnpm install --frozen-lockfile`.

**Why:** pnpm treats the modules dir as its own; a symlinked dir is not "someone else's", so every session sharing
`/projects/elohim/node_modules` inherits the damage, and the links die when the scratchpad is removed.

**How to apply:**
- A worktree (`.worktrees/*`, scratchpad) gets its OWN `CI=true pnpm install --frozen-lockfile` (network is reachable;
  `--offline` fails on `@pnpm/exe`). It takes ~20 s from the content-addressable store — never symlink.
- `CI=true` is required for a non-TTY install that must replace an existing modules dir.
- Sophia UMD assets for the app prebuild can be copied from the main checkout's
  `app/elohim-app/src/assets/sophia-plugin/` (check-sophia.sh Source 1) — a fresh sophia submodule clone has no dist.
- The cargo side has the same shape: a detached-HEAD worktree resolves to a COLD pool family named after its
  directory; write `sprint` (or the right family) into `<worktree>/.family` before `just gate`
  (`CARGO_TARGET_POOL_FAMILY` env did not reach the runner). See [[project_cargo_pvc_disk_discipline]].
- Related: [[feedback_push_branch_discipline]] (clean-worktree pushes are the norm; this is how they stay clean).
- A household mesh cannot live under a deep scratchpad path: Lair's unix socket path must be < 108 bytes
  (`path must be shorter than SUN_LEN`, conductor generate exit 1). Start it with `MESH_DIR=/tmp/hh/household-dowell`
  (short, explicit) and pass `MESH_HAPP_PATH` to the main checkout's packed hApp when the worktree has none.
  A RESUMED main household (persisted identities + a day of DHT) went into the documented CPU storm with
  `CellDisabled` on every conductor; a MESH_RESET of the shared fixture is classifier-denied, so cast fresh elsewhere.
