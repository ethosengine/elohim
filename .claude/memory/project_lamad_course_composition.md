# Lamad course composition (umbrella)

Folds the design memory of how learning content is composed in lamad — what a path is,
how a course becomes atoms, where assessments live, and what the graph is built on.
Members (each carried in full in its own file):

- [[fct-v2-recomposition-intent]] — the course is re-composed into EPR atoms so the medium reveals the protocol; all fifteen modules recomposed 2026-10-08 (`genesis/docs/content/fct/fct-course/recompose.py`), ids kept stable.
- [[paths-are-walks-over-epr-graph]] — a path is one walk over the graph; meaning lives on atom relationships so elohim can compose personalized paths like love maps; static path files are a concession.
- [[project-quiz-is-a-shadow-of-any-object]] — Operator 2026-10-08: a quiz is not a separate module or step; every object can carry one as its shadow (`VALIDATES`); surface it on the object, never as a sibling step.
- [[formation-cloud-imagodei-mapping]] — personalization joins the content cloud to the cloud that formed a person; author atoms as clean join points.
- [[project_content_graph_native_rust_not_cozo_apollo]] — the relationship graph is native Rust storage; Cozo/Kuzu/Apollo rejected — extend ContentGraphResolver.
- [[project_epr_link_first_class_seed_authoring]] — seed slug links drift silently; the seal tool is DEFERRED until docs graduate peer-native.
