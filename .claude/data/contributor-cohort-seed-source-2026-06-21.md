# Contributor-cohort seed source

The operator's LinkedIn announcement of the Elohim Protocol (elohim.host). Its **"Inspired by"
lists are the authoritative seed cohort** for contributor presences — the real people and
collectives that inspired the *vision* (distinct from the technical-dependency cohort: Khan/Perseus,
Holochain, libp2p, iroh, Automerge, hREA-as-software, gitoxide, Eclipse Che).

Operator intent: *"it would be very cool if all these folks had a contributor presence (even if only
inspirational) in the contributor knowledge graph."* The **"even if only inspirational"** qualifier
is the concrete low-commitment tier of the standing gradient (honored + witnessed via Layer-1; no
technical dependency; irreversible legs gated on a confirmable channel).

Architectural note from the same message: **collectives get their own presence too** —
`presenceType: organization` — and a presence is *"an attractor to the network … think Google Maps
crowdsourcing."* I.e. anyone can create the placeholder pin; the real entity later **claims** it and
receives accrued recognition. That is literally `ContributorPresence`'s "recognition before
registration" model stated as a **growth mechanism**, not just attribution.
