# No CLAUDE.md needed here

This directory holds the modular per-concern split of the lamad app manifest — pure JSON, no executable code. Each file is the value of one top-level manifest key (`attestations.json`, `content-formats.json`, `gates.json`, `graph.json`, `observation-kinds.json`, `observations.json`, `relationships.json`, `rendering.json`, `signals.json`) plus a `content-types/` subdirectory holding one file per contentType.

The convention is documented at the parent level in `elohim/sdk/CLAUDE.md` under "Modular manifests (lamad pattern)". A second CLAUDE.md here would duplicate that text.

The `$ref`-resolution mechanics are in `elohim/sdk/domains/lamad/scripts/codegen.mjs` (JS side, `resolveRefs`) and `elohim/elohim-storage/tests/lamad_manifest_registration.rs` (Rust side, `resolve_refs`). Both are scoped to `./manifest/*` and `../*` paths.

Sprint reference: `genesis/docs/plans/2026-05-18-app-manifest-modularization.md`.
