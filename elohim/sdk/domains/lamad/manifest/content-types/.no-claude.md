# No CLAUDE.md needed here

This directory holds 28 contentType definitions for the lamad app manifest — pure JSON, one file per contentType (concept, exercise, assessment, lesson, article, path, etc.). Each file is the object value of one `vocabulary.contentTypes.<name>` entry from the original monolithic manifest.

Adding a new contentType: write `<name>.json` here (2-space indented), then add `"<name>": { "$ref": "./manifest/content-types/<name>.json" },` to the manifest shell's `vocabulary.contentTypes` block.

Convention documented at `elohim/sdk/CLAUDE.md` under "Modular manifests (lamad pattern)". Sibling `.no-claude.md` at `manifest/` covers the broader rationale.
