# elohim-shell

Landing and host chrome. The non-pillar surface — the parts of an app that aren't owned by `imagodei`, `lamad`, `shefa`, `qahal`, or `doorway`.

## Scope

- Landing page sections: hero, vision, design-principles, call-to-action, path-forward, crisis, home, learning-success, elohim-host.
- App chrome: footer, theme-toggle, debug-bar, not-found.

## Source

`app/elohim-app/src/app/components/*` — preserves component file tree.

## Depends on

- `elohim-core` (tokens, breakpoints, base).
