1. **High — stale index membership leaks an ungranted manifest.** [blob_mount.rs:103](/projects/elohim/.worktrees/as-e3/elohim/eprfs/eprfs-peer/src/blob_mount.rs:103). Index two valid manifests with the same output CID: first an ungranted method, then a granted method. `by_output` replaces the first record, but `by_object` retains its manifest’s membership. An admitted sibling requests `Blob { artifact: output, cid: old_manifest }`: root admission uses the new granted method, `methods_of` incorrectly attributes the old manifest to that method, and membership passes. **The old, ungranted manifest is served**, exposing its derivation metadata. Remove obsolete reverse memberships or preserve authorization separately for each derivation.

2. **High — peer-origin events can establish local serving authority.** [blob_mount.rs:519](/projects/elohim/.worktrees/as-e3/elohim/eprfs/eprfs-peer/src/blob_mount.rs:519), [fold.rs:436](/projects/elohim/.worktrees/as-e3/elohim/eprfs/eprfs-peer/src/fold.rs:436). An admitted sibling publishes a `custody-blob` Produce with `copy:self`, `manifest:<cid>`, and an allowed measure/reason pair. Folding preserves those classifications and adds `via:<device>`. Indexing checks neither `via:` nor the custody receiver, so it treats the peer’s claim as local custody. **If the referenced manifest and descriptor already exist locally, the peer can cause indexing without a local custody Produce.** Payload reads remain `LocalOnly`; the defect is accepting peer-origin authority from the shared flow log. Reject folded events and bind custody to this holder.

3. **Medium — refusal deduplication does not bound event amplification.** [blob_mount.rs:488](/projects/elohim/.worktrees/as-e3/elohim/eprfs/eprfs-peer/src/blob_mount.rs:488), [daemon.rs:1122](/projects/elohim/.worktrees/as-e3/elohim/eprfs/eprfs-peer/src/daemon.rs:1122). An admitted sibling sends requests for continually changing, unknown artifact CIDs. Every CID creates a fresh dedup entry and queues another durable Use event. The queue is unbounded; the daemon drains and appends every event. **The attacker can drive memory, disk, and repeated flow-log scanning without receiving artifact bytes.** The 60-second window limits identical retries only. Deviation 8 supplies no aggregate bound.

4. **Medium — malformed policy reloads preserve existing access.** [daemon.rs:1068](/projects/elohim/.worktrees/as-e3/elohim/eprfs/eprfs-peer/src/daemon.rs:1068), [serves.rs:47](/projects/elohim/.worktrees/as-e3/elohim/eprfs/eprfs-peer/src/serves.rs:47). After a grant exists, replacing the policy with malformed JSON, an invalid serves shape, or an unknown audience leaves the previous grant active. A sibling can continue fetching on existing or new connections. **Parsing rejects the replacement, but runtime authorization does not fail closed.** Valid empty grants deny access, and valid grant changes reach subsequent requests. The cited [reload test:774](/projects/elohim/.worktrees/as-e3/elohim/eprfs/eprfs-peer/tests/serve_blob.rs:774) changes admission directly; it does not exercise policy-file reload.

5. **Informational — ordinary root-substitution attacks fail; the index defect is the exception.** [blob_mount.rs:601](/projects/elohim/.worktrees/as-e3/elohim/eprfs/eprfs-peer/src/blob_mount.rs:601), [tier.rs:481](/projects/elohim/.worktrees/as-e3/elohim/eprfs/eprfs-peer/src/tier.rs:481). Every artifact-byte answer passes `admit_root`, `admit_object`, and membership before fetching. An unrelated granted root cannot authorize another artifact’s object. Shared chunks across distinct outputs do not bypass the requested root’s grant. Bare chunk/manifest CIDs do not become roots merely because they are held; a chunk may legitimately also be an indexed complete output. Tree List/Read/Diff use only `ChannelStore`, so they provide no payload-store bypass. **Calling all gates is insufficient when their index is inconsistent**, as finding 1 demonstrates.

7. **Informational — manifest checks and Use-event isolation hold within limited boundaries.** [blob_mount.rs:310](/projects/elohim/.worktrees/as-e3/elohim/eprfs/eprfs-peer/src/blob_mount.rs:310), [blob_mount.rs:169](/projects/elohim/.worktrees/as-e3/elohim/eprfs/eprfs-peer/src/blob_mount.rs:169).
