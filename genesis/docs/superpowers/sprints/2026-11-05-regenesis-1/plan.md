## 0. Context (why)

The next sprint was to be the artifact store on the p2p dataplane. Reading Radicle/Heartwood for prior art, then reconciling it against our primitives, surfaced a foundation defect underneath that sprint: the protocol's byte address is a *string* with `sha256-` in a doc comment (DNA `ShardManifest.blob_hash`, `BlobEntry.hash`, every `/blob/sha256-…` route, 640 sites in elohim-storage), which is Radicle's bare-SHA-1 mistake in our integrity zome. Track E would mint the first artifacts under that profile, and a content-addressed plane cannot re-hash payloads it no longer holds — so the profile must be decided and landed *before* the artifact store, while nothing real exists to migrate.

**Operator decisions (2026-11-05, in this session):**
- Re-sequence: **sprint 1 = re-genesis 1, the address crossing; sprint 2 = the artifact store** (plan §7.3 as written, with R1 collapsed to a profile declaration).
- Generational architecture: rework to get the foundation right is accepted; a convenience that would have to be torn out is not.
- **Clean break, no migration:** "if we can save several days by cleaning everything and starting fresh, that's completely available." No dual-read of `sha256-` and BLAKE3, no compat shim, no equivalence index, no row migration. Field types change; the household is recast (`MESH_RESET=1`); alpha is re-genesised through the pipeline. The real network is one human; every other identity is a fixture. (Exceptions to confirm in §3: brit signed notes and device keys are not fixture state.)
- Orchestration: one Fable session (this one) orchestrates across **ethosengine** (this workspace) and **shem**, delegating to **Codex** (`gpt-6-astra` for reviews/challenges, `gpt-5.6-sol` for mechanical sweeps and reads), **Opus 5.5** (integrity surfaces, hard implementation), **Sonnet 5.5** (scoped implementation, tests). Done in days, not a week. The plan must hold enough context that the orchestrator schedules integration, delegates, and never loses the plot.

**The principle every piece instantiates:** every primitive that can age — hash, chunker, erasure code, signature scheme — is declared by code + parameters inside the object that uses it (CIDv1's multihash is the model). One profile per plane, every address self-described: DHT entry hashes stay Holochain blake2b (untouched); records and citations stay dag-cbor + sha2-256; **bytes become raw + BLAKE3 (`bafkr4i…`) at epoch 0** with FastCDC chunking declared in the profile.
