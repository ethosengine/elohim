## Why the row is missing: a seam, in mintable shape

`chain: leg 2 / between "root authored by the operator runtime" → "Che's storage serves the root" / missing node: projection of a hosted-cell-authored record into a storage peer / state: open.`

A storage projects rows only for writes it performs through its own conductor's native cell, and `POST /db/content` on the doorway writes as the storage node's agent (Che op-gate, `orchestrate-node`). A **hosted** cell has no storage behind it, so a record created directly on it reaches only the DHT, and the content reconcile arm never creates rows from the DHT (`projection_reconcile.rs` ~4420). The household never met this because its owner was a native peer with its own storage. Two resolutions, not mutually exclusive: the delegate adopts the root (the step above), and the operator runtime gets a storage of its own (steward tier), which the ruling above already names as the target.
