# Brit governed readiness foundation

The shared native developer entry is implemented locally. Epr owns one read-only
reconciliation and actionable projection; Brit delegates to installed epr. Native
habit declarations and covenant order are read from the selected repository.
Repository attribution is explicit; existing Elohim addresses remain unchanged.
No source-to-source copy of the engine, parallel work queue or new peer authority
was introduced. Changes are uncommitted and unpushed; no installed binary or
submodule pin was replaced.

## Boundaries and delivery

Brit declares local habits for feature reconciliation, inherited CI, native daily
driver and the Git comparison horizon. The family routing map preserves gix crate
ownership and distinguishes engine functionality from public behavior. Daily driver
and compatibility remain unwired; feature reconciliation and inherited CI remain
red. The foundation does not certify those product milestones.

Context ranks by declared covenant order and authored order, exposes environment
and seal blockers, and preserves the owners of existing commitments. Habit entry
follows explicit feature references and accounted work with bounded scope. Rejected
reviews, new production, changed reports and competing acceptance remain distinct
from completed production. The memory harness consumes this same view; recall and
semantic similarity do not grant acceptance.

## Running the candidate

From the parent repository, use the freshly built native evaluator with the newly
built Brit binary without changing the installed tools:

```sh
PATH=/tmp/eprfs-gate-target/debug:$PATH /tmp/brit-merge-target/debug/brit context docs/plans/2026-09-28-governed-readiness.md --root elohim/brit
```

First project Brit's current declarations using the candidate epr:
`/tmp/eprfs-gate-target/debug/epr flow project --root elohim/brit --recipes .epr-meta/recipes.yaml`.
The private `.eprfs/` projection is ignored by Git. For a standalone installation,
use installed epr and brit with the same arguments and `--root .`.
