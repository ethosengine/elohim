**b. CONFIRMED — a v3 host can falsely refuse runnable bytes.** Held-release admission keeps the last row in flow order per sibling and bin. Fetch judges **every** matching row for the output. **c. CONFIRMED — local recording can suppress sibling judgement.** `bin ingest` alone creates a store record and preserves the content-derived release CID.
