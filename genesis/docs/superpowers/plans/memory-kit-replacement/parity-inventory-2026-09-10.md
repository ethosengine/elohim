## Re-taken 2026-09-11 — station six, integration seat, round (a)

Evidence date: 2026-09-11. Same 53 artifacts, re-read against the tree after stations 3b, 4 and 5
did their deleting and relocating. **This is the section `epr flow report parity` evaluates.**

Three reading changes from the 2026-09-10 take, each deliberate:

1. **The `artifact` cell names the FULL kit path.** The bare filename was ambiguous once six scripts
   were relocated: a `procedure:` naming `.epr-meta/elohim/lenses/memory/memory-review.py` contains
   the substring `memory-review.py`, so a bare-filename token made a successful relocation read as a
   surviving consumer. The full path asks the question the row actually means — *does any executable
   reference to the KIT path remain?*
2. **`state` is measured, not declared** — `present` means the file is on disk right now; `deleted`
   and `relocated` are `git status` facts.
3. **`parity` uses the four values the plan's station six names** — `native` · `relocated` · `retired`
